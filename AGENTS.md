# Consola de liquidación

- La fuente del comportamiento acordado es `specs/001-liquidacion/spec.md`.
- Usa `src/liquidacion.mjs` para la regla de negocio. La UI y el instalador consumen esa misma función.
- Los importes son céntimos enteros. `src/reservas.mjs` contiene datos sintéticos de ensayo.
- Antes de dar un cambio por comprobado ejecuta `npm run check` y di qué casos pasaron. Conserva los valores esperados de las pruebas.
- Los cambios de GitHub, la revisión y la fusión se deciden en clase.
